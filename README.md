# ⏳ Memento Lock (메멘토 락)

> **"기억하라, 너는 언젠가 죽는다. — Memento Mori"**
> 인생의 유한함을 시각적인 게이지와 D-Day로 직시하고, 매 순간을 밀도 있게 살아가도록 돕는 미니멀 라이프 타이머 & 위젯 앱입니다.

---

## ✨ 핵심 기능

### 1. 80세 기준 인생 게이지 & `LIFE D+` 카운터
- 사용자의 **생년월일**을 기준으로 기대 수명 **80세**까지의 전체 일수 중 현재까지 지나온 인생의 비율(`%`)을 소수점 둘째 자리까지 계산합니다.
- 태어난 날부터 오늘까지 살아온 날을 미니멀한 **`LIFE D+11,496`** 배지로 함께 표시합니다.
- 생년월일은 **숫자 8자리 직접 입력(`19950515`)**과 **숫자 월(`1월~12월`) 전용 커스텀 달력 선택**을 모두 지원합니다.

### 2. 멀티 D-Day 목표 관리 (`[+ 추가]`)
- 이루고 싶은 인생 목표들의 **제목**과 **목표 날짜**를 개수 제한 없이 추가하고 삭제할 수 있습니다.
- 목표 카드를 탭하면 잠금화면 위젯에 노출할 대표 목표 **최대 2개(`위젯 1`, `위젯 2`)**를 즉시 지정할 수 있습니다.

### 3. 메멘토 모리 · 스토아 철학 · 각성 명언 95선
- 세네카, 마르쿠스 아우렐리우스, 니체 등 고전 철학 명언 **45선**과 정신이 번쩍 드는 강렬한 각성 문구 **50선**을 합쳐 총 **95선**을 내장했습니다.
- **노출 주기 설정:**
  - **하루에 한 번 (기본 추천):** 날짜 기반 시드로 하루 동안 하나의 문장을 고정 노출해 오늘의 화두로 삼습니다.
  - **볼 때마다 랜덤:** 앱이나 위젯을 새로 볼 때마다 무작위 문구를 노출합니다.

### 4. 위젯 2종 디자인 & 위젯 스타일 스튜디오
- **잠금화면용 위젯:** `인생 게이지(%) + 샌드베이지 바 + LIFE D+ + D-Day 최대 2개 동시 노출 + 한 줄 명언`이 컴팩트하게 담긴 다크 카드 레이아웃
- **홈화면 4×1 가로 배너형 위젯:** `왼쪽(인생 게이지 & LIFE D+) | 가운데(목표 제목 & 명언 2줄) | 오른쪽(대표 D-Day)` 3단 가로 분할 레이아웃
- **위젯 스타일 스튜디오:**
  - **배경 박스 투명도 조절 (0% ~ 100%)** 및 실시간 배경 시뮬레이션 (`노을 그라데이션` / `밝은 모래` / `어두운 밤`)
  - `밝은 모래` 배경 선택 시 가독성을 높이는 **딥 에스프레소(`#1F1A17`) 폰트 + 웜 브론즈(`#7A5230`) 포인트 + 크림 아이보리(`#F5F2EB`) 박스** 자동 추천 적용
  - **박스 컬러 / 텍스트 컬러 / 게이지·포인트 컬러** 개별 선택 및 **RGB 슬라이더 · HEX 코드(`[+ 옵션 추가]`)**를 통한 사용자 정의 팔레트 영구 저장

## 🛠 기술 스택 및 프로젝트 구조

- **Framework:** Flutter (Android / iOS / Web)
- **로컬 저장소:** `shared_preferences` (생년월일, 멀티 D-Day 목록, 명언 모드, 위젯 투명도 및 커스텀 컬러 팔레트 영구 저장)
- **폰트 내장:** `MementoSans` (`fonts/malgunsl.ttf`, `fonts/malgun.ttf` 로컬 번들링으로 한글 타이핑 및 새로고침 시 네모 박스 `⌧` 현상 완벽 제거)

```text
memento_lock/
├── lib/
│   └── main.dart          # 앱 전체 모델, 로컬 저장소, 커스텀 달력, 위젯 스튜디오, 메인/설정 UI
├── test/
│   └── widget_test.dart   # 인생 게이지, LIFE D+, 생년월일/HEX 파싱, 명언 95선 단위 테스트
├── fonts/                 # 내장 한글 폰트 (MementoSans)
└── pubspec.yaml           # 패키지 및 폰트 에셋 설정
```

## 🚀 실행 방법 (Windows)

### 1. 패키지 설치 및 테스트
```powershell
cd C:\dev\memento_lock
flutter pub get
flutter analyze
flutter test
```

### 2. 안드로이드 가상 휴대폰(Emulator)에서 실행
```powershell
flutter run -d emulator-5554
```
*(또는 프로젝트 폴더의 `run_mobile.bat` 파일을 더블클릭하면 가상 휴대폰 부팅부터 앱 실행까지 자동으로 진행됩니다.)*

### 3. 웹(Chrome)에서 실행
```powershell
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 8080
```
이후 브라우저에서 `http://127.0.0.1:8080` 접속
